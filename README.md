# Absentees 🎓📊  
A **Flutter-based attendance management application** designed to simplify tracking student attendance with an intuitive UI and real-time insights.

## 🌟 Features  
✅ **User-Friendly Interface** – Simple and intuitive design for easy navigation.  
✅ **Graphical Representation** – View attendance data using charts and graphs.  
✅ **Cross-Platform Support** – Works seamlessly on **mobile**.  
✅ **Real-Time Updates** – Efficiently track student attendance.  
✅ **Dark & Light Mode** – Switch between themes for better accessibility.  

## 🚀 Live Demo  
🔗 **Web App**: [Absentees Web](https://absentees-web.vercel.app/)  

## 🛠️ Tech Stack  
- **Frontend**: Flutter  
- **Backend**: MySqlLite
- **State Management**: Provider 

## 👅 Installation  
1. Clone the repository  
   ```bash  
   git clone https://github.com/Adamkoda2306/Absentees.git  
   cd Absentees  
   ```  
2. Install dependencies  
   ```bash  
   flutter pub get  
   ```  
3. Run the app  
   ```bash  
   flutter run  
   ```
